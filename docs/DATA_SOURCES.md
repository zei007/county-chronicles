# 数据来源与校准说明 · DATA_SOURCES.md

> 更新时间：2026-11。本作数据遵循"**真实锚点 + 标注估算**"原则：近年关键指标逐城核实自官方公报，早年份数据为公开资料整理的插值估算并在游戏内明示。

## 1. 校准方法

1. **采集**：对全部 43 座资源型城市，逐城检索《2023/2024年国民经济和社会发展统计公报》与《第七次全国人口普查公报》，提取：
   - 最新 GDP（亿元）与常住人口（万人）
   - 七普常住人口（2020-11-01 时点）
   - 可得的历史年份 GDP（2000/2010/2015/2020 等）
2. **注入**：`scripts/apply-patches.mjs` 将锚点写入城市 JSON 的 `timeline`（标记 `calibrated: true`）：
   - 锚点年已有条目 → 覆盖 pop/gdp
   - 锚点年无条目 → 插入"统计锚点"条目（`event:false`，不进事件流）
   - 末年估算值与最近锚点偏差 >1.8 倍 → 按趋势续接修正（避免图表末端断崖）
   - `space.peak_pop` 低于七普值 → 用七普校准
3. **标注**：每城 `sources[]` 记录数据说明与来源 URL，档案报告自动附"数据来源"章节。

## 3. 估算与口径说明

1. **早年份数据（1949 前）**：多数无系统统计，采用公开学术文献与地方志数字，游戏中标注"插值估算"。
2. **GDP 为当年价名义值**：不同年份不可直接比较增速，图表仅表现量级轨迹。
3. **人口口径**：优先常住人口；抚顺/阜新部分年份公报仅公布户籍人口，已在锚点 JSON 中注明。
4. **经济普查修订**：五经普（2024）修订值与原公报存在系统性差异（如石嘴山、墨竹工卡），锚点同时保留并注明。
5. **迁徙流向**：基于学术文献与公开研究整理，为估算值（游戏内已标注）。
6. **空置率**：无全国统一官方口径，采用调研估算值（鹤岗等收缩城市参考公开报道）。
7. **对照组城市**（深圳/上海临港等）用于"兴"的对照叙事，数据口径同上。

## 4. 主导产业产量数据

石油/煤炭/铜/金/锑/镍/锡/汞等产量序列来自：中国能源统计年鉴、行业协会年报（中国有色金属工业协会等）、公司年报与公开报道，多数城市含 5~13 个锚点年，中间年份线性插值。
